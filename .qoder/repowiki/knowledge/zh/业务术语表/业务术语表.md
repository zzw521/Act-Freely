### 通天办公
- 定义：项目正式名称，定位为「本地 AI 工作助手」，采用 Electron/Tauri 桌面应用形态，通过 AI Agent 能力帮助用户完成办公任务
- 别名：tongtian-office、通天

### AgentBridge
- 定义：主进程与 Python Agent 子进程之间的通信桥接层，负责子进程生命周期管理、端口分配（18000-19000）、健康检查、SSE 事件解析转发
- 别名：agent bridge、代理桥

### 工作区
- 定义：多智能体协作的工作空间概念，每个任务在一个独立的工作区内执行，包含文件操作、配额管理、安全沙箱等能力
- 别名：workspace、工作空间

### 能力域
- 定义：产品功能模块按职责划分的领域单元，如 agent-engine、audit-logging、compliance、file-processing、mcp-integration、sandbox、schedule-cron、skills-system、workspace 等 12 个能力域
- 别名：capability domain、能力模块

### 两阶段协议
- 定义：计划生成（plan → pending_review）和执行（executing → step_* → deliver/done）分离的任务执行流程，支持用户审阅和调整计划后再执行
- 别名：plan-review-execute、两阶段执行

### 事件重放
- 定义：SSE 流中断后通过 Last-Event-ID 机制从内存重放窗口（≥10min，2048条上限）中恢复事件序列的能力，确保事件零丢失
- 别名：event replay、断线续传

### Mock Agent
- 定义：开发调试用的模拟 Agent 服务，纯标准库实现，提供完整的 SSE 事件序列（plan → step×3 → deliver → done），用于脱离真实模型联调 UI 流程
- 别名：mock agent、模拟代理

### 引擎模式
- 定义：通过 TT_ENGINE 环境变量控制的三种引擎选择：mock（开发调试）、agentscope（默认真实引擎）、qwenpaw（遗留兼容），支持运行时切换
- 别名：engine mode、引擎选择
