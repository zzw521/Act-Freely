该模块是纯脚本集合，按职责划分为四类：
- 环境准备：`download-env.ps1` 从清华/华为镜像下载 JDK8 与 Maven 并解压到 `.tools/jdk8` 与 `.tools/maven`；`setup-env.ps1` 校验解压结果；`setup-rust.ps1` 通过 rustup + rsproxy 镜像安装 Rust 工具链。
- 构建与运行：`compile-all.ps1` 顺序编译 `bpaas-user`、`bpaas-product`、`order-service`；`start-product.ps1` 执行 `mvn install` 后以 dev profile 启动 Spring Boot；`stop-tauri-dev.ps1` 按端口 7173 查找并终止 Tauri/Vite 进程。
- 探针与诊断：`probe-agentscope.ps1`、`inspect-agentscope.ps1`、`probe-hooks.py`、`probe-qwenpaw.ps1` 用于探测 Python agentscope/qwenpaw 包版本与 API 签名。
- 测试：`test-engine-smoke.ps1`、`test-mock-agent.ps1` 启动 Python HTTP 服务并通过 curl 验证 /health 与 SSE `/api/chat` 接口。
所有脚本共享硬编码的 `$base = "d:\aliyun-ptam\sdd-release-v1-local\sdd-release-v1-local"` 路径约定，通过设置 `JAVA_HOME` 与 `PATH` 临时注入 JDK8 (jdk8u492-b09) 与 Maven 3.9.x，不修改系统全局环境。
