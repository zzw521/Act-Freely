- 每个 PowerShell 脚本开头设置 `$ErrorActionPreference = "Stop"` 并在关键命令后检查 `$LASTEXITCODE` 决定是否退出。
- 所有外部工具路径通过硬编码的 `$base` 变量拼接 `.tools\jdk8\...` 与 `.tools\maven\...`，并通过覆盖 `env:JAVA_HOME` 与 `env:PATH` 临时生效，不修改系统级环境变量。
- 对外部进程调用统一采用 `& cmd ... 2>&1` 形式捕获 stderr，并用 `Write-Host` 打印分节标题（如 `=== Step X ===`）便于日志追踪。
- Python 相关探针通过 `python -c "..."` 内联单行代码或 `python -m pip list | Select-String` 过滤关键字来探测包状态，避免引入额外依赖。
