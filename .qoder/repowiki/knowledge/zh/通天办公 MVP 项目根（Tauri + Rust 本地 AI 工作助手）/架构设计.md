根目录作为 Cargo workspace 与 Vite/React 前端的统一入口，按能力域在 `src-tauri/crates/` 下划分独立 crate（agent、model-hub、file-ops、storage、workspace、skills、mcp、sandbox、python-bridge），由 `src-tauri/src/main.rs` 启动并注册 Tauri command；前端 `src/` 仅通过 `@tauri-apps/api` 的 invoke/listen 调用后端，所有跨语言类型由 `ts-rs` 从 Rust struct 自动生成到 `shared/` 目录，形成单向类型同步管线。Python 侧仅作为可选 sidecar（JSON-over-stdio 契约、MockSidecar 进程内拦截），不构成运行时依赖。数据持久化与密钥存储集中在 storage crate，运行目录遵循 SPEC v2.1 双目录契约（安装目录只读，用户数据位于 `%USERPROFILE%\.tongtian-office`）。
