- Rust crate 命名采用 `tongtian-{域}`（包名）与 `crates/{域}`（目录）对应，模块/函数 snake_case，类型 PascalCase
- Tauri command 统一 `domain_action` 命名（如 chat_submit、model_test），event 统一 `domain://name` 格式（如 agent://event）
- 前后端共享类型通过 ts-rs 从 Rust struct 自动生成至 `shared/`，禁止手写修改
- 错误处理统一 AppError { code, message, details? } 结构，Rust 侧 tracing 分级日志，敏感字段脱敏
- 配置与模型 Key 经 keyring/系统密钥库加密存储，绝不明文落盘或硬编码，`.env.example` 仅占位
- 外部接口依赖均以 MOCK_ENABLED=true + cargo feature mock 切换为本地模拟实现，联调阶段关闭 Mock
