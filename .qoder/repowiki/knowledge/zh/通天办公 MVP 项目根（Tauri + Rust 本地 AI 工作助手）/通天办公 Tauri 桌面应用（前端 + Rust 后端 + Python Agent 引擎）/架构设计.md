模块采用三层架构：
- 前端渲染层 `src/renderer/`：React + Vite + Tailwind + MUI，通过 Zustand store 管理状态，页面按功能分目录（Workbench、ModelHub、Settings、Security 等），组件按职责拆分到 `components/`。
- 主进程/预加载层 `src/main/`：Electron main 进程入口（index.ts）负责窗口、托盘、IPC 注册；`src/preload/` 暴露安全 API 给渲染进程。
- Rust 后端 `src-tauri/`：Cargo crate 通过 `#[tauri::command]` 暴露系统信息、Agent 生命周期、任务提交/审阅/控制/取消、模型管理、文件操作、设置持久化等命令；使用 rusqlite 做本地存储，keyring 存密钥，tokio 异步运行时处理并发。
- Python Agent 引擎 `engine/server.py`：FastAPI + uvicorn 提供 HTTP/SSE 接口，实现 ReActAgent 的两阶段协议（plan→review→execute），支持事件重放、keepalive、pause/resume/rollback_to。
- Mock 服务 `scripts/mock-agent.py`：纯标准库实现的代理，用于开发期零依赖测试。
- 数据流：前端 → Tauri command → Rust bridge → HTTP 调用 Python engine → SSE 事件回传 → 前端事件流解析器。
