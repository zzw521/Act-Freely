- 所有 Tauri 命令通过 `#[tauri::command]` 宏声明，并在 `lib.rs` 的 `generate_handler![]` 中集中注册，参数统一使用 `State<'_, Arc<P0Services>>` 注入共享服务。
- SSE 事件遵循统一的 `id: {task_id}:{seq}` / `event: {type}` / `data: {json}` 三行格式，每个事件携带单调递增的 seq 字段用于断线续传和重放。
- 两阶段协议严格区分 stage=plan（仅生成计划待审阅）与默认全流程执行，审阅动作 approve/reject/modify 通过 `/api/chat/review` 统一处理。
- 任务状态机使用 14 种状态（queued/planning/pending_review/executing/paused/done/failed/cancelled/archived/rolled_back 等），状态转移通过 `update_status` 原子更新并同步 emit 事件。
- 错误码采用 `CODE: 描述` 字符串格式（如 `QUOTA_EXCEEDED`, `TASK_NOT_FOUND`, `VALIDATION_ERROR`），便于前端分类处理和用户提示。
- Python 引擎与 Mock 服务保持完全一致的 HTTP/SSE 契约，通过环境变量 `.env` 配置 TT_PROVIDER/TT_MODEL/TT_API_KEY/TT_BASE_URL 切换不同 LLM 提供商。
