通天办公 MVP 项目的配置系统采用「环境变量 + JSON 配置文件 + SQLite 设置库」三层叠加的架构，分别服务于 Python Agent 引擎、Rust/Tauri 后端和前端 Electron 主进程。

## 1. 使用的框架与工具
- **Pydantic v2**：Python 侧所有配置模型均通过 pydantic.BaseModel 定义，使用 Field、model_validator、field_validator 进行类型校验、默认值、别名映射与迁移逻辑。
- **json_repair**：加载 config.json 时自动修复常见语法错误（尾逗号、注释、BOM 等），失败则回退到默认配置并备份原文件。
- **ContextVars**：运行时上下文变量（工作目录、会话 ID、Toolkit、AgentState 等）通过 contextvars.ContextVar 跨工具调用传递。
- **SQLite (rusqlite)**：Rust 侧通过 rusqlite 直接读写 settings_kv 表；Electron 主进程通过 sqlite3 存储应用级设置。

## 2. 核心文件与包
- tongtian-tauri/.env / .env.example：TT_PROVIDER、TT_MODEL、TT_API_KEY、TT_BASE_URL 等 LLM 提供商密钥与环境端点。
- src/agent/config/config.py：完整的 Pydantic 配置模型（ChannelConfig、LightContextConfig、HeartbeatConfig、ReMeLightMemoryConfig 等 20+ 个配置类）。
- src/agent/config/utils.py：配置加载/保存/缓存/迁移的核心逻辑（load_config、save_config、_read_config_data、_load_and_validate_config）。
- src/agent/config/context.py：运行时 ContextVar 封装（workspace_dir、session_id、toolkit、agent_state 等）。
- src/agent/config/timezone.py：跨平台 IANA 时区检测（Windows 注册表、Linux /etc/timezone、timedatectl、TZ 环境变量）。
- src-tauri/src/store/settings.rs：Rust 侧 settings_kv 表的 get/set/all 操作。
- src/main/store/settings-store.ts：Electron 主进程应用设置（语言、主题、开机自启、保持唤醒等）的内存缓存 + SQLite 持久化。
- src-tauri/tauri.conf.json：Tauri 应用元数据（productName、version、identifier、窗口尺寸、安全策略）。

## 3. 架构与设计决策
- **分层加载顺序**：
  1. 环境变量（.env 中的 TT_* 变量）→ 覆盖默认值
  2. config.json（WORKING_DIR 下）→ Pydantic 校验 + json_repair 修复
  3. 内置默认配置 → 作为最终兜底
- **热重载与缓存**：load_config 使用 mtime 检测避免重复磁盘读取，进程内 _config_cache + _config_mtime 保证并发安全。
- **向后兼容与迁移**：
  - weixin → wechat 字段名自动迁移
  - 旧版 last_api_host/port → last_api.host/port 结构迁移
  - 损坏配置自动备份为 .bak 或 .migration-name-migrate.bak
- **运行时上下文隔离**：每个 Agent 会话通过 ContextVar 注入独立的工作目录、会话 ID、Shell 超时、可执行文件等，避免多 Agent 间污染。
- **双持久化层**：
  - Python 侧：config.json 存储结构化配置（channels、agents、memory 等）
  - Rust/Electron 侧：SQLite 存储键值对设置（settings_kv、app_settings）

## 4. 约定与约束
- **环境变量命名规范**：LLM 相关统一以 TT_ 前缀（TT_PROVIDER、TT_MODEL、TT_API_KEY、TT_BASE_URL）；通道开关通过 QWENPAW_ENABLED_CHANNELS / QWENPAW_DISABLED_CHANNELS 控制。
- **配置文件位置**：所有用户配置位于 WORKING_DIR（可通过 QWENPAW_WORKING_DIR 自定义），包括 config.json、dialog/、mem_metadata/、resource/ 等子目录。
- **安全约束**：
  - .env 已被 .gitignore 忽略，禁止提交密钥
  - Tauri 安全策略中 CSP 设为 null（开发模式），生产环境需显式配置
  - Agent ID 必须匹配正则 ^[a-zA-Z0-9][a-zA-Z0-9_-]*[a-zA-Z0-9]$，长度 2-64，保留字 default 不可用
- **容错机制**：
  - JSON 解析失败时自动修复，仍失败则回退默认配置并备份原文件
  - 验证错误时尝试移除问题字段后重试，最多一次修复机会
  - 时区检测失败时降级为 UTC，永不抛出异常
- **线程安全**：配置缓存读写通过全局锁保护；运行时 API 地址通过原子赋值保证单写多读安全。
