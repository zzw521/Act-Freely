本文件只做**任务分工**，不含实现。分 7 个窗口，每窗口一张所有权表；卡号指会话任务列表里的 #137–#165。

## 0. 拆分的三条硬前提

**① 本仓库不是 git 仓库。** 没有 diff、没有 merge、没有回滚。两个窗口写同一个文件 = 后写的把先写的静默覆盖。所以分工的依据不是"任务像不像"，而是**文件所有权不重叠**。

**② 三处热点文件是所有引擎/桌面改动的公共咽喉：**

| 文件 | 行数 | 谁必须碰它 |
| --- | --- | --- |
| `tongtian-tauri/engine/server.py` | 8955（61 个路由装饰器） | 任何新增引擎端点或工具注册 |
| `tongtian-tauri/src-tauri/src/lib.rs` | 2911（`generate_handler!` 注册面） | 任何新增 IPC 命令 |
| `tongtian-tauri/src/shared/contracts.ts` | 3721（IPC 通道常量） | 任何新增命令的前端接线 |

7 个窗口同时改这三个文件必炸。解法见 §1 的 W4 前置接缝卡 #164：**先由一个窗口一次性写完注册面，之后其他窗口只填自己命名的模块文件。**

**③ 已有在线批次正在动的文件（截至 18:01）：** `src-tauri/src/harness/runner.rs`（3683 行）、`lib.rs`、`suite/mod.rs`（2032 行）、`market/mod.rs`、`skill/*`、`tongtian-server/app/desktop_index.py`、`engine_task_budget_realmodel_selftest.py`。这些是**禁区**，要动之前先 `stat -c '%y %s %n'` 看 mtime 是否仍是别人的时间戳，别用"看起来没改"当证据。

## 3. 每窗口通用纪律（贴进 kickoff 提示词）

- **领地判定**：动手前 `stat -c '%y %s %n'` 逐个确认自己要写的文件；mtime 不是自己的时间戳 → 先回报，别改。
- **自测命名不撞车**：每窗口只新建/编辑 `tests/integration/engine_<自己域>_selftest.py` 与自己域下的 `tests/unit/**` 文件；`defect-ledger-contract` / `builtin-tools-contract` / `step-replay.test.ts` 归 W4。
- **引擎自测必须用 `./vendor/python/python.exe -X utf8`**（`.venv` 缺 docx/pptx 会整族 SKIP 且 rc=0，看着像绿其实没跑）；判定只看 `^\[PASS\]` 计数，日志写文件再窄式 grep，别信回显。
- **Rust 只走 `bash scripts/run-rust-tests.sh [filter]`**；裸 `cargo test --lib` 会 0xc0000139 崩。
- **耗时断言不许贴着睡眠值**：vendor 的 `time.monotonic` 是 GetTickCount64（粒度 15.6 ms）。
- **全量 vitest 有既有红**：放闸前先跑一次 `npm run test` 并记下红的**文件名清单**作为本窗口基线（本会话最近一次实测：105 文件里 1 红，红在 `task-budget-execution-contract`，它钉的 Rust 调用形状属在线批次；在线批次另报过 5 红 / 4 文件）。只允许修自己改动造成的红，其余红写进分片上报，不要顺手改别人测试。
- **契约测试会钉跨语言形状**：TS 源码契约测试连 Rust 的 borrow 写法都会被钉成不变量；改签名要同步改 pin 并声明动了谁的领地。
- **台账回填不许超出实测**：真机没跑就写"未验收"，自测绿不等于实机绿；不许用"工具链缺失"当挡箭牌（D-22 白名单段外，台账任何行都不得出现"工具链"三字）。
