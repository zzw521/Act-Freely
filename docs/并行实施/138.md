**进展（2026-11-03，W2 #138）**：

- **留档点在写入之前**：`record_current(path, task_id=, tool=, reason=)` 存的是
  **即将被盖掉的那一份**，不是写完之后的新内容——所以版本 `0001` 的内容等于第一次覆盖前
  盘上那一份。自测按「取那一版正文」逐版比对（不是按版本号顺序猜内容）。
  文件还不存在时**不算失败也不硬造版本**，回执写清「首次创建，没有旧内容需要留档」，
  调用方不需要自己判断该不该调。
- **文件系统就是台账**：`{数据根}/artifact-history/{产物路径 sha256 前 16 位}/{0001-时间戳.后缀}`
  ＋ 同名 `.meta.json` ＋ 文本另存 `.diff`。**刻意不写中心 `manifest.json`**：七窗口在
  非 git 的同棵树上并发，共享清单必然互相覆盖；路径哈希用 `normcase` + `resolve`，
  Windows 大小写与 `8.3` 短名造成的「同一产物两个目录」不会出现。
- **元数据带得齐**：`origin / sha256 / bytes / mtimeMs / capturedAtMs / text / codec /
  task / tool / reason / previousVersion / blob / diff / diffNote`。`bytes` 是**副本的实际字节数**
  （自测按这个口径断言，不是按原始文件 stat）。
- **逐字节相同不重复留档**：只跟**最近一版**比 sha256，命中就返回 `deduped` 并把版本号
  指回已有那一版（回滚路径尤其吃这条，见下）。
- **文本留 diff，二进制不装**：`unified_diff` 走行级比对，超过 `MAX_DIFF_LINES=4000`
  **不生成半截 diff**，只在 `diffNote` 里说明「两版正文都完整留档，可整版回滚」；
  字节不同但行级相同（换行符换了）也不写空 diff 文件。二进制版本 `text=false`、
  没有 `diff` 也没有 `codec`，向它要差异时**如实拒绝**，不拿乱码冒充 diff。
- **回滚三条硬规矩**：① 只写回它**留档时记录的那个路径**——把 A 的副本拷进 B 的历史目录
  再让 B 回滚到那一版会被拒（自测真造了一个「张冠李戴」现场），拒绝这句话点名两边路径；
  ② 写回前先把当前内容留成一版 ⇒ 回滚本身可回滚；**这一步留不住就不覆盖**
  （宁可回滚失败也不做第二次不可逆写入）；③ 原子替换（`.tmp-` + `os.replace`），
  失败路径不留半截文件。当前内容正好等于最近一版时，第 ② 步走去重：版本号指回已有那一版、
  历史长度不变、该写的还是写了——这条不是失败，自测按三个独立断言钉住。
- **配额清理有下限**：`prune(keep=20, max_total_bytes=256MB)` 两段式，先按产物削到只留
  最新 `keep` 版，再按总量预算从最旧开始删，**但每个产物的最后一版永不删**；
  删到极限仍超预算时把这件事说出来（「剩下的都是各产物唯一可回滚的那一版，不再删」），
  并给出删了几版、释放多少字节。单份超过 `MAX_TRACK_BYTES=4MB` 则**拒留档并写清实际字节数**，
  覆盖照常进行——不悄悄少留。
- **端点面**：五个都真挂上（`rl.attach` 报告 `lane=knowledge / endpoints=5`），
  读面 `GET`、写面 `POST` 都先过路径闸；缺参 400、数据根外 403（`ARTIFACT_PATH_DENIED`）、
  回滚失败 422 并带 `note`；请求体不是 JSON 时按缺参处理而不是 500。
  `stats` 与盘上独立数一遍的副本数一致（自测自己 `rglob`，不用实现的私有函数自证）。
- **零注册面负担**：本刀没有新工具名 ⇒ `side_effect_registry` 四表、
  `toolkit_lanes.RESIDENT_TOOLS`（仍六件）、`builtin-tools-contract` 都不需要动；
  `routes_lanes._prefix_ok` 已按**段**对齐，`/api/artifact`（W4）与 `/api/artifacts`（W2）
  不会互相认成本家——这条是 W4 在接缝里就写好的，本刀只是受益方，不是本刀的成果。
