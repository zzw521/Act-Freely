## 3. 状态明细（给要接手的窗口：实际形状）

新增两份模块（**纯标准库，`engine/requirements.txt` 与 `requirements.lock.txt` 一行未改**）：

- `engine/crash_runtime.py`（850 行）——本机崩溃现场。对外：`install(engine_version=…, loop=…)` / `record(...)` / `handle_exception(...)` / `detail` / `list_reports` / `export` / `delete` / `status` / `describe` / `set_recorder` / `recorder_state` / `installed_state` / `runtime_info` / `redact_secrets` / `REDACTION_KINDS` / `CATEGORIES`。
  - 三个钩子：`sys.excepthook`、`threading.excepthook`、`loop.set_exception_handler`；`server.py` 另有请求级 `@app.exception_handler(Exception)`（类别 `http_unhandled`）。钩子在 `uvicorn.run` 之前装，循环钩子在 lifespan 补装，两半各自兜底。
  - **脱敏在落盘之前**：`_SECRET_PATTERNS` 五类（认证头 / 键值凭据 / 模型密钥 / JWT / 长随机串），每条是 `(类名, 正则, 替换, 取值判据或 None)`。判据走回调**不要**改回正则里的多个 `(?=…)`——64 KB 长串上是平方级扫描，处理崩溃的代码会自己变成故障源。
  - 留存口径：上限 `MAX_REPORTS` 满了丢最旧并计数、同类同栈在 `DEDUPE_WINDOW_MS` 内合成一条并 `times` 累加、正文截断 `MAX_TRACEBACK_BYTES` 并如实标 `traceTruncated`、上下文只认五个键且只收标量（被丢的键进 `_droppedKeys`）。
  - 导出=**副本 + sha256**（名字到毫秒，秒级会撞车）；删除必须指名道姓，`*` 一律拒。
  - 本模块**不认识** `telemetry_runtime`：观察者是装配现场 `crt.set_recorder(_crash_observer)` 登记的。
- `engine/telemetry_runtime.py`（740 行）——可选遥测。对外：`consent_state` / `set_consent` / `decisions` / `record` / `preview` / `flush` / `discard_all` / `configure_sink` / `sink_state` / `read_state` / `status` / `describe` / `ALLOWED_FIELDS` / `FIELD_VOCAB` / `KINDS` / `CONFIRM_WORD`。
  - 默认关：没有同意文件 = 关，**读坏了也是关**（改名让路 + `loadError`）。四个分支（absent/corrupt/invalid/file）的键集合必须一致，否则 `status()` 这个只读动作自己 `KeyError`（本卡真踩过）。
  - 开启要 `word=AGREE`（只记「给过了」，不记词本身）；**关闭不设门槛**、当场删缓冲并换 `installationId`。
  - `preview()` 与 `flush()` 共用 `_rows_from()` ⇒ 预览是逐字。`_rows_from` 取 **`rows[:size]`（先进先出）**：切 `rows[-size:]` 会让缓冲长期大于批次时最旧那条永远发不出。
  - **没有出口时绝不写「已发」**：回话与计数器同一句 `NO_SINK_SUMMARY`；`_drop_delivered` 按 `eventId` 精确移除。
  - 出口只能进程内 `configure_sink()` 登记；HTTP 面拒绝任何想设定出口的键（`TELEMETRY_EGRESS_NOT_SETTABLE`，整条 400，不静默丢键）。

端点（`engine/routes_exec.py`，exec 车道、desktop-only）：`/api/exec/telemetry/{describe,status,preview,decisions,consent,flush,discard}` + `/api/exec/crash/{describe,status,list,detail,export,delete}`；`EXEC_ENDPOINT_PATHS` 由 13 → **26**。业务性拒绝回 **200 + `{ok:false, reason}`**，缺参与服务故障才 400/500。

契约（`src/shared/contracts_exec.ts`）：13 个响应接口 + `CrashReportRow` / `TelemetryConsentState` / `TelemetryEventPayload` 等行形状；自测从 `.ts` **刮字段名**与实际回话双向对键（不手抄清单）。两条口径已写进注释：`CrashReportRow` **不带** `reason`（`reason` 属于 detail 响应），`TelemetryFlushResponse` **故意不声明** `endpoint/note`（没有真实接收端之前不声明拿不到的东西）。

错误码：本族只用独立 `code` 字段（`TELEMETRY_*` / `CRASH_*`，自测数到 14 个以上），**不用** `"CODE: 详情"` 那种形状——那种会被 `tests/unit/shared/error-surface-contract.test.ts` 要求逐条进 `error-messages.ts`。

自测抓出的九个真缺陷（都已修，接手时别退回）：JSON 形状凭据漏打、脱敏糊掉 64 KB 栈正文、现场编号只到秒、导出文件名撞车、`loopHook` 读数停留在上次 install、`consent_state` 四分支键不一致、`flush(limit=)` 被位置调用、`_rows_from` 切片方向反了、两处「没有出口」说法不同源。

另有一件自测自身的卫生修复：本文件的临时数据根此前只 `mkdtemp` 不清理，绿跑一次在 `%TEMP%` 留一个永久目录；现在 `atexit` 收尾删除，**红了才保留**（失败时把现场目录扫掉等于「案发现场找不到」），并被 §1 一条用例钉住不许写回去。

## 4. 未验收与边界

1. **设置页一行未接**：`src/renderer` 没有开关、没有将发送内容预览面板、没有崩溃记录列表。要接的话只需 `engineFetch` 直连本机引擎，不必打开 `contracts.ts` / `lib.rs`。
2. **Rust 侧零**：无本族命令、无 IPC 通道（自测反向钉住「没做的那一半不许被读成做了」）。
3. **没有接收端**：真实投递、退避、失败重投、批大小与网络中断后的行为全部未验；`configure_sink` 只有自测里那两个假出口。
4. **崩溃不自动外发**：永远靠用户手动导出附件；导出物已脱敏，但「用户会不会把没打到的东西发出去」没有防线，只有提示位。
5. **真机未演练**：桌面包已 `stage-engine.mjs` 刷新（87 条目，含两份新模块），但没重建安装包、没开窗口，没有「崩一次 → 界面看得到那条」的实证。
6. **同意入口的 UI 没有** ⇒ 「显式同意」这条验收只有引擎侧闸门成立。
